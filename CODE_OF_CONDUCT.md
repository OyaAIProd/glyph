# Code of Conduct

This project adopts the **[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its Code of Conduct. The full text is published at the canonical URL
above; we vendor by reference (not by copy) so the document stays
versioned and up to date with the upstream.

The short version: be kind, assume good intent, ask before assuming.

## Reporting

If you experience or witness behavior that violates the Contributor
Covenant in any Glyph community space — GitHub Issues, Discussions, PR
review threads, or in-person events under the Glyph banner — please
contact the maintainers privately by opening a **security advisory** at
<https://github.com/seanhanca/glyph/security/advisories/new> (advisories
are visible only to repo admins; "security" is the right channel for
private maintainer contact on GitHub).

Reports are read by the maintainer team and handled per the Covenant's
[Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).

## Scope

The Covenant applies in any space affiliated with this project —
GitHub-hosted threads, our Discord (if/when we add one), conference
talks given on behalf of Glyph, and any other forum where someone is
representing the project.
