Draw-in animation

A parametric Archimedean spiral (t·cos(t)/8, t·sin(t)/8) that traces itself over 3 seconds. The new animation.kind: "draw-in" emits a SMIL <animate> on stroke-dashoffset — no JavaScript, no extra files. Drop it onto any line, area, or contour mark.

Spec

{
  "version": "glyph/0.1",
  "title": "Archimedean spiral — pen-draw",
  "data": {
    "function": {
      "shape": "function",
      "parameter": { "name": "t", "min": 0, "max": 25, "samples": 200 },
      "xExpr": "t*cos(t)/8",
      "yExpr": "t*sin(t)/8"
    }
  },
  "layers": [
    {
      "mark": "line",
      "encoding": {
        "x": { "field": "x", "type": "quantitative",
              "scale": { "domain": [-3.5, 3.5] } },
        "y": { "field": "y", "type": "quantitative",
              "scale": { "domain": [-3.5, 3.5] } }
      }
    }
  ],
  "animation": { "kind": "draw-in", "duration_ms": 3000, "easing": "ease-in-out" }
}
What's new: animation.kind: "draw-in" shipped in Math Phase 2 / Track A2. The renderer computes each path's polyline length with a pure, deterministic helper (rounded to 8 decimals via roundPx) and emits a SMIL <animate> on stroke-dashoffset from length → 0, frozen at the endpoint. Composes with any line / area / contour mark.
