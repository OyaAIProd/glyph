Sine wave

y = sin(x) sampled 200 times on [-2π, 2π]. The data.shape: "function" block tells the compiler to synthesize rows directly from an expression — no CSV file, no linspace helper.

Spec

{
  "version": "glyph/0.1",
  "data": {
    "function": {
      "shape": "function",
      "x": { "min": -6.283185307179586, "max": 6.283185307179586, "samples": 200 },
      "expr": "sin(x)"
    }
  },
  "layers": [
    {
      "mark": "line",
      "encoding": {
        "x": { "field": "x", "type": "quantitative" },
        "y": {
          "field": "y",
          "type": "quantitative",
          "scale": { "domain": [-1.2, 1.2] }
        }
      }
    }
  ]
}
What's new: the "function" shape was added in Math Phase 1 / PR1. Before, you had to generate the sample rows yourself (Python, Node, Excel) and import a CSV. Now the compiler does it deterministically with the expr-eval evaluator.
